# 科研原型 v3：课题即特殊群聊

仅本地 demo，位于 `demo/research-tab` 分支。没有加入正式 navbar、路由或数据库，不部署正式站点。

```sh
npm run dev -- --host 127.0.0.1 --port 8802
```

打开 `http://127.0.0.1:8802/demos/research/index.html?light`。支持 `?dark`、`?lang=en`。父页面禁止访问业务 `/api` 和跨域 fetch；日历通过独立 Chronelle iframe 自行读取受限展示接口。不会写入真实科研、群聊或日历数据。

## 已确认的产品规则

- 创建课题即创建专属群聊；不再关联已有群。课题是群聊的一种特殊业务形态，类似投稿。
- 课题与群聊共用成员、负责人来源。邀请自动同时加入；成员移除、负责人转让、退出、解散仅在课题详情操作。
- 群聊入口不提供独立转让群主或解散能力，展示说明并可直接进入课题详情。
- Header 不再提供日夜切换。菜单中切换主题和模拟身份。
- 课题必填起始时间，终止时间可以选任意未来日期或暂不设结束。
- 所有研究记录均对课题成员可见；进度默认只看自己，可以看全部或指定成员；评论与回复统一按真实时间点倒序。

## 主布局

- 时间线：课题边界、里程碑、论文截止占位及会议；可添加节点。论文示例日期不是已核实的会议截止日期。
- 阶段任务：成员分配、起止日期、Markdown 正文、附件和 HTTP(S) 链接。
- 进度评论：Markdown 编辑/预览、引用回复、每条最多 9 张图片、图片查看，直接在任务内操作。
- 课题资源：本地文件与链接。
- 日程与会议：改为 Chronelle `/binding-embed/{display_id}/`，默认本人，勾选成员发送 `set-calendars` 合并。时间选择回传后打开预约，保留完整时长并预选勾选成员。日历空白不表示空闲；预约仅检查本地会议冲突，会议暂存本地且不会回写 iframe 或发送邀请。
- 三点详情：成员列表、邀请、移除、转让、退出/解散与二次确认，不另加成员管理子菜单。

## 本地能力与边界

- 数据保存在 IndexedDB `frienden-research-demo-v3`。原型 v1/v2 不自动迁移，以免把旧版私密记录意外转换为共享评论。
- 图片及文件读成本地 data URL，最大每个 8 MB。评论/回复最多 9 张图片。未上传服务器；不要输入敏感资料。
- Markdown 是安全子集：多级标题、段落、粗斜体、行内/块代码、引用、列表、表格、HTTP(S) 链接；不是完整 CommonMark，不执行 HTML。任务、评论、回复与会议复用格式工具栏和编辑/预览组件，选中文字后可包裹语法。
- 创建群、邀请、会话消息、成员管理、退出/解散均只改变本地示例。正式版必须由服务端强制执行权限与课题/群的一致性。
- iframe 遵循 Chronelle `docs/bindings/EMBED-BRIDGE.md`，校验精确 origin、source window、channel、最新 request ID、协议版本及时间范围。重载换频道；20 秒超时，失败隐藏旧 iframe 内容。空选择和部分可见范围均不推断空闲。
- 联调配置只接受官方双域名或 loopback 的 `/binding-embed/UUID/` URL，不接受查询/fragment/密钥。展示 ID 不是权限，仍要求 Chronelle 查看者会话；localhost 白名单仅用于本地 demo。每个查看者/课题独立保存 URL，过期需更换。不能把旧公开分享链接当展示会话。
- 正式完整绑定、刷新、服务端身份映射及 display-session 签发尚未接入；不能宣称已实现真实账户“自动看自己”。本地模拟身份默认选择对应展示会话，私密凭据不会交给浏览器。Safari 跨站会话限制按 Chronelle 返回状态展示，不绕过。
- Markdown 表格支持 10×10 浮动网格选择（行数包含表头），并复用站内下拉框。
- 不复用旧版“关联现有群”逻辑，不复用旧版个人记录保密策略。

`node --test demos/research/*.test.ts`

## 隔离 iframe 联调

使用隔壁 Chronelle 后端虚拟环境运行 `demos/research/run-chronelle-qa.py`。脚本创建全新临时 SQLite 和合成日历，监听 `127.0.0.1:8031`，打印四个 15 分钟展示 URL。打开 `/qa-session/` 建立固定合成查看者会话，再把 URL 填到 Frienden 联调配置中。仅测试真实 Chronelle shell/读取/消息协议，不测试生产登录、OAuth 同意或真实邀请，不连接生产数据库；不要部署此夹具。

实际浏览器已验证默认本人、两人合并和重叠排版；自动化无法聚焦跨域网格，点击/拖选的实机回传仍需人工验证。协议解析和时长、来源、旧请求拒绝由测试覆盖。
