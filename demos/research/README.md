# Research Tab / 科研 Tab 本地原型

本地预览，不接入正式导航、路由、业务 API 或数据库，也不迁移 Supervision 数据。

```sh
npm run dev -- --host 127.0.0.1 --port 8802
```

打开 `http://127.0.0.1:8802/demos/research/index.html`。独立端口可避免接触现有预览的登录状态。支持 `?dark`、`?light` 和 `?lang=en`。状态仅存放于该浏览器源的 `frienden:research-demo:v2`，删除该键可恢复示例。

## 设计依据

阅读相邻 `Guidances/Supervision` 的 README、任务/记录/成员/会议模型及工作区实现。迁入科研工作流，不迁入独立账号、Frienden 绑定、重复聊天和上传系统。

- 一个课题作为工作上下文；Header 切换进行中、筹备中和已完结课题。
- 创建者为导师；导师发布任务、指定成员、安排会议、邀请同空间好友。
- 所有课题成员可以查看全部任务说明；进展、总结与导师反馈仅对应学生本人和导师可见，多人任务不改变个人记录边界。
- 写进展、总结与导师反馈直接在任务详情内编辑，不再打开二级 Drawer；会议议程和纪要在会议列表内展开。
- 主导航精简为任务、会议、成员；删除独立记录 Tab、重复标题和周度标语。
- 课题可以关联导师已加入的已有群，或本地模拟创建包含课题成员的专属群；关联不自动修改已有群成员、不发送个人记录。
- 任务采用列表与详情；小屏只显示当前层级，低高度保留紧凑导航。
- 复用 Frienden 的主题、图标、DrawerTabs、BottomSheet、SideDrawer。未增加正式 Tab。
- 已完结课题只读；导师可通过设置重新开启。正式版需后端强制校验。

## 可以操作

课题切换、新建课题、修改课题状态；所有成员查看任务说明；任务筛选、发布与状态切换；导师/学生视角切换；内联学生记录/总结、定向导师反馈；会议发布与内联纪要；好友选择与模拟加入；关联已有群或模拟新建专属群；深浅色切换。上述内容本地保存。

## 明确未接入

好友邀请的接受/拒绝、真实建群与群成员变更、实时会话、真实文件上传、Chronelle 忙闲/日历、消息提醒、任务级讨论、服务器权限、Markdown/数学编辑器、真实时间和时区校验。群聊面板只保存本地关联关系，不冒充真实会话，也不发送消息。与既有成员不完全相同的群可以关联；实际邀请与群访问权限仍需正式版独立处理。

示例人物与内容均为虚构。不要输入敏感科研数据。视角过滤仅用于展示，浏览器本地数据不是权限边界。UI 文案通过本原型 `copy.ts` 的中英字典管理，科研样例内容不翻译。

## 待共同确定

已确认：既可关联已有群，也可新建专属群；学生可看他人任务说明，个人进展、总结和导师反馈不互见。

仍待确定：邀请的接受流程、会议同步 Chronelle 的方式、任务截止日期是否必填。正式落地时需由后端过滤个人记录，不将本地视角过滤当成安全边界。

## 验证

`npx tsc -p demos/research/tsconfig.json` 检查 demo；`node --test demos/research/model.test.ts` 检查视角过滤。`npm run build` 检查正式应用不受影响。正式构建没有包含本 demo 的入口。
