# Administrative boundaries

The files in `adm1/` are simplified first-level administrative boundaries from
[geoBoundaries](https://www.geoboundaries.org/) `gbOpen`, licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Regenerate them with `npm run maps:cache`. Pass ISO alpha-3 country codes to
refresh only selected countries, for example `npm run maps:cache -- CHN USA`.
