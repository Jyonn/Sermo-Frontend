# Brand artwork

Production Frienden icons live in `public/icons/frienden-*.png`. The PWA manifest
and page entry declare the sizes they consume. `public/icons/sermo-192.png`
remains for the brand migration notice.

Retired Sermo concept pages, wordmark exports and unused sizes have been removed;
Git history retains their originals. `frienden/` is a separate design workspace,
including a locally edited preview. It is not copied into production and remains
untouched by the cleanup.
