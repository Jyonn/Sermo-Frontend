# 言浪设置操作设计语言

设置界面不按业务模块创造新布局，而按交互目的组合 `SettingGroup`、`SettingRow`、`SettingSwitch` 和 `SettingSelect`。

## 六类操作

1. **即时开关**：标题和必要说明在左，Switch 固定在右。
2. **下级入口**：整行可点击，右侧使用箭头；进入 Drawer、Sheet 或独立页面。
3. **值编辑**：右侧先展示当前值，再展示箭头或编辑图标；点击后用 Modal 修改单一值。
4. **单选菜单**：选项少且切换风险低时使用自绘 `SettingSelect`。
5. **只读状态**：右侧只展示值或 Badge，不伪装成可点击控件。
6. **危险操作**：沿用相同行结构和危险色，点击后进入确认流程。

## 状态修饰

- 等级、VIP、认证等限制使用 `locked`，它是状态，不创建新的布局。
- `disabled` 同时禁用交互并弱化整行，辅助文字解释原因。
- 新功能红点和引导通过 `trailing` 组合，不改变标题层级。
- 加载只替换右侧控件，不让整行改变高度。

## 信息层级

- 标题描述“是什么”，不重复操作指令。
- Description 只解释后果、限制或当前状态。
- 当前值位于右侧并允许截断，完整编辑放在 Modal 或下级 Drawer。
- 同组项目共享一个外框和分隔线，不为每行单独套卡片。

## 不使用设置行的场景

个性化外观预览、媒体选择、成员头像网格、统计摘要和内容 Feed 保留独立组件。统一的是操作语法，不是把所有内容变成列表。

## 颜色

组件只使用当前版本已有的主题变量、品牌绿、危险色和 Switch 配色。统一聚焦排版、间距、层级和交互，不重新定义言浪配色。
