# Code Duel Digits

- Typeface: Space Grotesk, sourced from the Google Fonts official repository.
- Original font blob: `a1b2e6c26093066510a31147e7aec9abdc8d6c5e`.
- Source: https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- License: `public/fonts/space-grotesk-OFL.txt` (SIL OFL 1.1).
- Local subset: `public/fonts/frienden-duel-digits-v1.woff2`.
- Coverage: digits, arithmetic signs, timer punctuation and question marks; ordinary text retains the site's fonts.
- Features: variable weights 300-700, lining/tabular numerals, slashed zero for code clarity.
- Processing: FontTools subset with WOFF2 compression. No external font service is required at runtime.
