# BGM keychain artwork

The original two-column concept sheet has been retired. Production uses the
separate transparent `public/activity/bgm/device-blue-v2.png` and
`device-pink-v2.png` housings with real interactive buttons rendered on top.
Banner, activity and chat components share these current assets.

Prompt: Two complete oval six-button music keychain toys side by side on a genuinely transparent background, powder blue and blush pink, three circular tactile keys above and three below, silver keyring and star charm, original cute manga protagonist stickers, premium softly lit plastic rendering, no words, logos, numbers, floor or cropping.
