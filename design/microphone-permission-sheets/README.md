# 麦克风授权 BottomSheet 设计提案

打开 `index.html` 可并排评审四种手机端麦克风授权前置说明。此页面仅用于本地设计比较，不会请求真实麦克风权限，也不修改正式聊天页。

- 01 静默确认：最低信息密度，单一主操作，延续聊天页静默工具栏的克制视觉。
- 02 权限阶梯：用三步结构解释应用说明、系统授权与按住录音之间的关系。
- 03 按住才录：以隐私边界为主标题，强调授权不会立即录音。
- 04 工具延续：保留聊天工具栏缩影，让授权说明与触发入口形成连续关系。

顶部可以切换首次授权、权限已关闭和深色模式。正式落地时建议优先评审 `01 静默确认` 与 `03 按住才录`。
