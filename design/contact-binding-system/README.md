# 联系方式绑定系统

本方案将账号类绑定和即时提醒 App 绑定聚合为同一套视觉与交互骨架。

## 信息架构

- **账号与送达**：电子邮箱、手机短信、QQ 号。
- **即时提醒应用**：Bark、ntfy、Gotify、PushDeer。
- **统一流程**：渠道识别 -> 填写接入凭据 -> 验证码确认 -> 绑定回执。
- **共享组件**：六位验证码区域对应生产环境已有的 `VerificationCodeInput`，不另造输入逻辑。
- **动态差异**：仅图标、辅助色、字段定义、准备说明和安全提示由 provider metadata 驱动。

## 视觉原则

应用图标与品牌辅助色只用于渠道识别，Sermo 绿色始终承担主操作和成功反馈。Drawer 不跟随每个 App 改变整体皮肤，避免账号设置页产生拼贴感。

直接打开 `index.html`。左侧可切换七种渠道，顶部可切换填写、验证、完成状态以及 Drawer 深浅主题；页面同时提供手机窄屏布局。
