# 友间来信 · 品牌融合四案

本地预览：`/design/letter-brand-variants/`

- 青绿信笺：暖白纸张、青绿信件，最接近当前产品主题。
- 夜间来信：墨绿背景、浅色信纸，呼应深色聊天界面。
- 蓝绿邮戳：青绿为主，品牌蓝只点缀邮戳和轨迹。
- 双色套印：保留上一版的暖意，但珊瑚色仅作为少量印记。

四案都把「进入友间」交给 `/pwa`，不提供账号或最近空间入口列表。此目录是设计预览，不替换正式主页。

每案页面 Header 的月亮/太阳按钮可切换亮色和暗色；语言按钮可在中文与 English 预览状态间切换。英语译文尚未实现，切换后明确提示文案仍保持中文。
