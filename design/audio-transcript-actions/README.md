# 语音转文字入口设计

打开 `index.html` 可分别比较“转文字”入口与转写结果排版。预览按 `390px` 手机宽度设计，同时展示他方与我方消息。

- 01 中线轻胶囊：常驻在气泡朝向屏幕中线的一侧，发现性最好。
- 02 雾点图标：空闲时仅保留文字图标，加载和展开后显示状态文案。
- 03 下沿签注：操作位于气泡外部下沿，不与播放信息争空间。
- 04 长按菜单：不提供常驻入口，通过长按气泡调用。

第二部分提供六种转写结果样式：贴合续页、无框字幕、声纹脚注、轻纸便签、消息旁白和编辑稿。

页面支持明暗模式切换。点击任意“转文字”入口可观察加载、展开、收起和再次展开状态；长按菜单方案也可通过点击语音模拟。
