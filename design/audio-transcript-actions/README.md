# 语音转文字入口设计

打开 `index.html` 可比较六种把“转文字”移出语音气泡的方案。预览按 `390px` 手机宽度设计，同时展示他方与我方消息。

- 01 中线轻胶囊：常驻在气泡朝向屏幕中线的一侧，发现性最好。
- 02 雾点图标：仅保留文字图标，最节省横向空间。
- 03 下沿签注：操作位于气泡外部下沿，不与播放信息争空间。
- 04 时间同轨：把操作降级为消息元信息，与发送时间并列。
- 05 长按菜单：不提供常驻入口，通过长按气泡调用。
- 06 点按渐显：默认隐藏，点按语音气泡后在中线侧浮现。

页面支持明暗模式切换。点击任意“转文字”入口可观察转写文字展开；第五、六版可点击消息体验渐进操作。
