SERMO

Logo Redesign / Direction 01

从高级时装的克制字标出发，把“说话”做成一种空间，而不是一个聊天图标。白底、近黑、正方形；真正的识别来自比例与沉默。

克制不借助彩色、渐变或拟物，用字距和尺度建立品牌重量。
社交断口、换行与游标暗示一来一回，但避免常见气泡符号。
国际纯英文 SERMO，接近时装编辑体系，适用于中文与英文界面。
可缩放每一案都在 512 × 512 正方形中成立，并接受 16 px 压力测试。

Five directions

不是字重微调，而是五种不同的品牌性格。

Monument / 纪念碑

01

最接近高级时装语汇的一案。极紧字距、强横向张力，像建筑铭牌一样稳定，不依赖任何图形说明自己。

PRIMARY WORDMARK · 稳重 / 直接 / 长寿

Dialogue / 对话

02

SER 与 MO 分成两次发言，右下实心块是等待输入的游标。更年轻，也更适合应用图标。

APP ICON · 社交 / 编辑感 / 高识别

Aperture / 开口

03

让 O 留下一道入口：既是嘴形，也是一个尚未结束的谈话。品牌含义藏在字母内部，而不增加图标。

SIGNATURE DETAIL · 开放 / 聪明 / 现代

Index / 索引

04

像书脊、刊头和服装织标。黑色横带把 SERMO 变成内容世界里的分类索引，适合启动页与运营物料。

EDITORIAL SYSTEM · 权威 / 内容 / 标签化

Whisper / 低语

05

不是更大声，而是更有余地。两点标记谈话的两端，中间的 SERMO 像一句被认真听见的话。

PREMIUM LOCKUP · 安静 / 文艺 / 留白
