# SERMO Logo Redesign — Concept Round 01

本轮探索以白底、近黑字、正方形为硬约束，借鉴高级时装品牌的克制比例与编辑感，但不复刻任何既有字标。

打开 `preview.html` 查看五个概念、反白测试和小尺寸压力测试。

## 概念

1. **Monument**：紧致横向字标，最适合作为长期主标。
2. **Dialogue**：两行对话结构，最适合作为应用图标。
3. **Aperture**：在 O 中留下“开口”，把交流含义藏进字形。
4. **Index**：服装织标与出版索引语汇，适合品牌系统。
5. **Whisper**：以留白表达被倾听，气质最安静。

这些文件是概念稿，尚未替换现有应用图标或线上品牌资产。
