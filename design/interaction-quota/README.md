# 互动额度面板设计提案

打开 `/design/interaction-quota/` 查看四套可交互方案。

- `01 余波`：推荐。把“今天还能做什么”作为唯一主信息，其余额度沿轨道展开。
- `02 双账`：把 24 小时与 7 天两套窗口并排对照，适合重度用户精确查看。
- `03 通行证`：以当前等级权益为中心，额度像通行证印记，产品感更强。
- `04 节律`：按发言、评论、匿名、点赞的节奏纵向阅读，信息最克制。

可操作内容：切换方案、手机/桌面宽度、横滑等级权益卡、模拟发言消耗。

主面板只保留当前可行动信息。周期额度、评论尺度、匿名条件与发言形式合并进入横向等级卡片，不再用独立的形式区块，也不把规则压缩成“7天15言”一类口语化短句。桌面与手机使用同一套单列阅读结构，仅调整等级卡片的可见宽度。
