# 桌面聊天输入工作台

本地预览：`/design/desktop-chat-composers/index.html`

四个版本都将聊天主区域明确拆成“上方消息记录 + 下方独立输入工作台”，并复用同一组消息、能力与状态，方便只比较输入体验：

- 阔幅书写台：最接近参考图，工具栏在上、书写区在下，迁移成本最低。
- 侧轨编辑台：高频工具放在左侧纵向轨道，为正文保留最大横向宽度。
- 上下文叠页：将回复信息、草稿和发送动作组织成一张叠页，关系感最强。
- 快捷指令桌：媒介入口使用图标，提及、常用回复、位置和足迹使用文字快捷项。

预览支持版本切换、明暗主题、紧凑/舒展高度、工具面板、回复取消、字符计数以及输入发送回显。该目录仅用于本地设计评审，尚未接入正式聊天页。
