# QQ 空间数据装订台

用于在浏览器本地把 QQ 空间 HTML 导出的 `messages.json` 整理为三张表：

- `qzone_user`：仅包含 `qq`、`nickname`，同一 QQ 保留时间上最新的昵称。
- `qzone_post`：保留说说作者、原始 ID、正文、媒体、发布时间和原始负载。
- `qzone_comment`：保留评论作者、所属说说、父评论、明确的回复目标、正文和发布时间。

## 使用

1. 直接打开 `index.html`。
2. 依次添加 HTML 导出文件夹，例如 `江中东墙HTML`、`江中西墙HTML`；每次选择会继续累加，也可以直接选择同时包含两者的上级目录。工具会自动寻找各目录内的 `Messages/json/messages.json`。
3. 可选依次添加 Markdown 导出文件夹，例如 `江中东墙`、`江中西墙`；工具只收集各目录内的 `Messages/YYYY.md` 进行数量校验，并忽略 `index.md`、图片及其他文件。
4. 在“人工整理”中处理普通文字 `@昵称` 无法确定 QQ 的记录，并对损坏的 QQ 内部提及进行增删改查。
5. 未确定的回复可以软删除；一级评论删除时会同时排除其嵌套回复，且均可恢复。
6. 分别导出三张 CSV，或导出完整 JSON。

所有文件只在当前浏览器内解析，不会上传网络。
