# 八仙聊天气泡角色完整动作设计 v4

## 定位

这不是统一模板换皮。三位角色拥有不同的动作动机、节奏、重心和次级运动。动画只表现角色自身动作；角色在气泡上的整体路径、左右镜像选择和气泡尺寸适配由前端负责。

制作基准为 24fps，但不要求三个角色帧数或时长一致。关键姿态使用逐帧或骨骼关键帧制作，中间帧必须由同一角色绑定/同一镜头连续计算，禁止用独立生成图片插帧。

## 通用表演原则

1. 先有动作动机，再有位移：视线或手先动，头肩跟随，衣袖与头发最后到达。
2. 进入和退出不是互相倒放。退出时角色已经完成动作，重心、视线与次级部件状态必须不同。
3. 主动作前必须有反向预备，主动作后必须有缓冲和余振。
4. 脸、胸腔和骨盆形成稳定主质量；手、剑、元宝、袖口与头发形成次级运动。
5. 动作弧线不能折线化。剑尖、元宝中心、手腕和发尾均应沿可检查的弧线运动。
6. 角色局部动画不得承担沿气泡边框移动的职责。前端只能移动角色根节点，不能替代角色关节动作。
7. 默认半身可见，允许手、道具和衣袖短暂超出半身盒；不得为了塞进画布缩成全身小人。

## 吕洞宾：探边、拔剑问候、挽花收剑

### 性格

克制、有志、干净利落。他不是炫技型剑客：动作准确，停顿有自信，剑花只做一次。

### 建议长度

96帧，4秒，24fps。

### 完整动作

| 帧 | 阶段 | 角色动作 | 次级运动与节奏 |
| --- | --- | --- | --- |
| 01–08 | 试探 | 指尖先搭住不可见边缘；停两帧确认支点 | 袖口最后才贴近边缘 |
| 09–20 | 探身 | 眼睛、额头、头和右肩依次出现；目光先扫正文，再看用户 | 马尾滞后3–4帧，末端轻摆 |
| 21–31 | 稳住 | 上半身上提，肘部压住边缘；胸腔一次很浅的呼吸 | 身体略过冲后回落2px；保持3帧形成可读剪影 |
| 32–39 | 预备 | 视线转向剑柄；持剑手反方向微压，肩膀先收 | 这是主动作的反向预备，剑仍在鞘中 |
| 40–54 | 拔剑 | 肘带动前臂，剑沿斜上弧线拔出；手腕在末段才旋转 | 剑尖速度先慢后快，剑穗落后4帧 |
| 55–67 | 剑礼 | 只做一次小型腕花：剑尖画约120°弧后停在胸前斜线 | 第61帧附近速度峰值；末端允许一帧小剑光，不做拖尾 |
| 68–74 | 定格 | 看向用户，轻轻点头；剑保持稳定 | 头先下、发尾后下；停2帧让问候被读懂 |
| 75–87 | 收剑 | 眼睛先找到鞘口，再由肘和腕把剑送回；最后两寸明显减速 | 剑穗继续摆动后衰减，不能和剑同步停止 |
| 88–96 | 退场 | 肩先退、头后退、手指最后松开 | 不倒放入场；离开前视线仍朝用户 |

### 必须绑定的部件

- 胸腔/肩线
- 头与颈
- 前后两段马尾或发束
- 持剑上臂、前臂、手腕
- 剑、剑鞘、剑穗
- 抓边手与袖口

### 禁止

- 大跳、腾空或整个人沿边框爬行
- 连续多次剑花
- 剑身凭空出现、长度变化或穿过手掌
- 用整张人物图旋转代替手腕和手臂动作

## 钟离权：懒散登场、元宝小抛接、耸肩离开

### 性格

松弛、吊儿郎当、带一点“这有何难”的幽默。他的节奏比另外两人慢，重心更沉，动作存在不对称。

### 建议长度

108帧，4.5秒，24fps。

### 完整动作

| 帧 | 阶段 | 角色动作 | 次级运动与节奏 |
| --- | --- | --- | --- |
| 01–12 | 冒头 | 两只手先搭边；头顶和眼睛缓慢升起，停一下观察 | 左右手错开2帧，避免机械同步 |
| 13–27 | 撑起 | 一侧肩先上，另一侧随后；胸腹压在边缘上，重心下坠 | 长发和外袍明显滞后，身体到位后仍晃一次 |
| 28–38 | 找东西 | 低头摸出元宝，先掂重量，再抬眼看用户 | 元宝在掌中有一次很小的下沉回弹 |
| 39–48 | 预备 | 手掌下压3–4px，手指张开；眼睛先看向预计抛物线顶点 | 肩膀不跟着大动，突出手腕懒散感 |
| 49–62 | 小抛 | 元宝沿短抛物线离手，最高只超过手掌约半个元宝高度 | 手腕先加速、手指最后弹开；元宝旋转不足半周 |
| 63–73 | 等待与接住 | 他不急着追，眼睛跟随；手背微转后把元宝接回掌心 | 接触瞬间手掌下沉缓冲，袖口再追上 |
| 74–86 | 把玩 | 拇指把元宝推到指根，手掌翻正；嘴角略扬 | 元宝必须始终只有一个，遮挡关系清晰 |
| 87–97 | 耸肩 | 空闲手摊开，双肩一高一低地耸一下，表达“就这样” | 头部反向偏移，长发晚3帧回位 |
| 98–108 | 沉回 | 手先收元宝，胸腹慢慢下沉；最后只剩眼睛和搭边手 | 下沉到一半时再瞥用户一次，手指最后滑走 |

### 必须绑定的部件

- 胸腹主质量和左右肩
- 头颈、长发前后层
- 托元宝上臂、前臂、手掌与五指姿态
- 元宝独立旋转和抛物线控制器
- 空闲手、宽袖、外袍下摆

### 禁止

- 元宝复制成两个或在帧间变形
- 水平走路或全身出现
- 抛得过高、像杂耍表演
- 左右肩、双手和头发完全同步

## 何仙姑：衣袖引路、短滑翔、致意转身

### 性格

飒爽、轻盈、判断迅速。她不是悬浮贴纸：进入时有方向，停下时有制动，退出由转肩带动衣袖和头发。

### 建议长度

90帧，3.75秒，24fps。

### 完整动作

| 帧 | 阶段 | 角色动作 | 次级运动与节奏 |
| --- | --- | --- | --- |
| 01–09 | 衣袖先行 | 指尖和前袖从边缘进入，手腕指向前进方向 | 袖口展开但不贴成直线，末端晚2帧跟上 |
| 10–22 | 头肩进入 | 视线先看向前方，随后转向用户；头、肩、胸依次出现 | 马尾沿相反方向拖曳，形成速度感 |
| 23–36 | 短滑翔 | 胸腔沿浅弧移动；前手略收，后肩降低，身体开始制动 | 移动距离只服务入场；衣袖仍比躯干多走几像素 |
| 37–45 | 制动 | 胸腔先停，头部轻微过冲再回正；视线锁定用户 | 马尾越过中心线后回摆，袖口做一次衰减波动 |
| 46–58 | 手势预备 | 致意手从胸前抬起，肘先动、手腕后动；另一侧肩向后打开 | 手指在接近面部时才分成双指 |
| 59–66 | 双指致意 | 双指停在面颊外侧，眉眼短暂带笑；保持3帧 | 头向手势方向倾约2°，不能整张人物图一起倾斜 |
| 67–77 | 转肩 | 手指合回，手臂放下；头先转向出口，肩和胸随后旋转 | 马尾与透明袖沿外弧甩出，形成清晰随动 |
| 78–86 | 离开 | 躯干先越过边缘，手和头发仍留在画面中 | 袖子不能与身体一起消失，应晚3–4帧 |
| 87–90 | 尾韵 | 最后只剩袖尖和一小段发尾，轻摆后离开 | 不透明度保持稳定，用遮挡退出，不做淡出鬼影 |

### 必须绑定的部件

- 胸腔、左右肩与颈部
- 头部、前发、马尾根部和发尾
- 致意上臂、前臂、手腕、双指手型
- 引路手与前后两层透明衣袖
- 腰带与可见裤腰，用于确认转肩方向

### 禁止

- 只把完整人物横向移动
- 长距离飞过整条气泡
- 用透明度淡出代替身体被边缘遮挡
- 袖子、马尾和胸腔同时启动、同时停止

## 制作与验收

### 推荐管线

优先使用 Spine、Live2D、After Effects Puppet、Blender 2D/3D绑定或其他带稳定角色绑定的动画工具。ImageGen可以生成角色设定、分层部件修补和关键姿态参考，但不得直接批量生成最终连续帧。

### 输出

- 原始工程应保留分层和骨骼，不只提交合成帧。
- 渲染透明PNG序列；画布建议384×384或512×512，前端显示64–96px。
- 每个角色单独导出，不烘焙气泡边框或全局路径。
- 附动作事件：`enterComplete`、`signatureStart`、`signatureEnd`、`exitStart`、`complete`。
- Web端优先导出透明WebM或AVIF/WebP序列；逐帧spritesheet作为兼容方案。

### 验收清单

- 以25%速度观看时，脸、手和道具无跳变、重影或形变。
- 每个动作都能指出预备、主动作、缓冲和随动。
- 剑尖、元宝、手腕和发尾轨迹是连续弧线。
- 任意相邻帧不存在人物身份漂移或道具数量变化。
- 去掉角色根节点位移后，角色内部仍然有清晰可读的动作。
- 在64px实际显示尺寸下，主动作无需放大即可识别。
