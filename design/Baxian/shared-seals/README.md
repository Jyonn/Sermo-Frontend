# 《八仙！》角色印章

三枚印章共享相同的竖向“八／仙／！”字标、鎏金内框、圆角长印轮廓和矿物颜料质感，以角色颜色与法宝区分。

| 角色 | 背景 | 配饰 | 生产文件 |
| --- | --- | --- | --- |
| 吕洞宾 | 深靛蓝 | 纯阳剑与青色剑穗 | `lv-dongbin-blue-seal.png` |
| 钟离权 | 暗朱红 | 圆形金色信物与橙色短绳 | `zhongli-quan-red-seal.png` |
| 何仙姑 | 藕荷粉 | 黑漆竹编斗笠与短粉纱 | `he-xiangu-pink-seal.png` |

每枚还提供 `*-seal-288.png`（192 × 288 标准画布）和 `*-seal-96.png`（64 × 96 气泡小标）。`source/` 保存 ImageGen 原图。

## 气泡使用

- 推荐显示高度：移动端 44–54px，桌面端 52–64px。
- 印章放在气泡尾角或人物动画的对角，人物和印章不得相互遮挡。
- 角色开始出场时，印章可做 140–180ms 的 `opacity 0→1` 与 `scale(.94)→scale(1)`；此后保持静态。
- 三枚印章共用同一定位组件，只根据角色 ID 替换资源；不要分别复制三套布局代码。
- 不要横向排字、旋转印章、循环跳动或给印章添加跑马灯。
- 低动态模式直接显示最终静态状态。

## 重建

```bash
python design/Baxian/build_seal_assets.py
```

脚本只去除源图的伪透明背景并输出统一尺寸，不重新绘制印章。
