# 电影《八仙！》聊天气泡素材

本目录维护电影《八仙！》三位角色的克制型聊天气泡动效源文件。

## 最终素材

- `character-action-bible-v4.md`：三位角色完整动作、自然时长、绑定部件和验收标准；下一轮正式动画制作以此为唯一动作依据。

- `*/restrained-12/`：三位角色的 12 帧关键姿态，也是 24 帧版本的可重建源。
- `*/restrained-24/`：在关键姿态之间加入中间帧的正式流畅版本；普通聊天使用此版本。
- `*/restrained-48-v2/`：重新设计的生产版本；单一一致半身木偶通过确定性缓动生成48帧，24fps、2秒，无AI姿态交错造成的跳变或双影。普通聊天只使用此版本。
- `*/restrained-48-v3/`：光流动画实验，仍不足以作为最终角色动画，仅用于问题回溯。
- `build_restrained_animations.py`：从关键姿态和中间帧重新构建 12/24 帧产物。
- `restrained-chat-bubble-usage.md`：Codex/前端接入、触发、定位和低动态模式规则。
- `imagegen-prompts-restrained-12.md`：本轮内置 ImageGen 提示词与共同约束。

## 气泡应用建议

- 人物位于气泡上缘之外，正文区至少保留 24px 内边距。
- 推荐浅暖纸色背景、橙金双线边框和低透明度“8”字水纹。
- 当前所有自动生成的12/24/48帧版本均视为动作实验，正式接入应等待依据 `character-action-bible-v4.md` 制作的绑定动画。
- 新消息短动效只播放一次，不随组件重渲染或滚动回屏重复播放。
