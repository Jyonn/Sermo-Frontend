# 八仙独立透明人物素材 v1

以 2026 年电影群像为造型参考生成的八个独立全身 PNG。所有成品使用相同的方形透明画布，保留人物自然体型差异；张果老与完整白驴作为一个骑乘组合素材。

## 目录

- `png-1024/`：设计母版和高分辨率界面使用
- `png-512/`：常规 Web 展示
- `png-256/`：头像、气泡边缘和缩略图
- `source-chroma/`：用于生成透明通道的纯绿中间稿，不应直接用于产品
- `process_chroma.py`：从中间稿重新生成三档透明 PNG

## 使用约定

- 使用 `object-fit: contain`，不要再次裁掉人物道具或张果老的白驴。
- 同组并排时保持画布尺寸一致即可，不要把人物非透明边界强制等高；体型差异是设计的一部分。
- 若作为气泡边缘装饰，优先使用 256 或 512 版本，并以元素自身画布定位，避免逐角色写不同裁剪参数。
