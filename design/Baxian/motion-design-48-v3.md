# 八仙聊天气泡 · 48帧角色动作规范 v3

## 设计原则

v3不再依赖整体人物平移，也不把独立生成姿态直接交替播放。每个角色使用8个按时间排序的半身关键姿态，关键姿态明确改变头、肩、手臂、道具、头发与衣袖；中间帧由双向稠密光流扭曲生成，使像素沿动作轨迹移动。

整体位置只用于角色从气泡边缘出现和退出。识别动作来自角色内部关节与次级部件：

- 吕洞宾：抓边探身 → 手腕靠近剑柄 → 剑身出鞘至胸前 → 收剑 → 低头点头 → 退回。
- 钟离权：双手搭边升起 → 托住元宝 → 手腕下沉预备 → 元宝小幅上抛 → 接住 → 双肩松弛耸起 → 沉回。
- 何仙姑：指尖和衣袖先入场 → 头肩跟进 → 上身短滑翔 → 双指靠近面部致意 → 手臂放下 → 转肩 → 头发和衣袖延迟退出。

## 时间

- 48帧，24fps，总时长2000ms。
- 每帧使用41/42ms组合；GIF预览使用40/50ms组合，两者累计均为2000ms。
- 关键姿态位于第0、7、14、21、28、35、42、47帧。
- 每一阶段使用smoothstep时间曲线，关键姿态间不做线性透明叠化。

## Codex接入要求

1. 只接入 `restrained-48-v3`；禁止使用v2的纯平移动画。
2. 不要在前端再次给人物主体添加平移关键帧。只按 `animation.json` 的锚点固定在气泡外侧。
3. 播放2000ms后隐藏；新消息首次进入可视区只播放一次。
4. 推荐64px，最大72px。放大会暴露光流中间帧的微小纹理变化。
5. 线上优先使用 `animation-48.webp`；需要精确结束事件时使用spritesheet或48张PNG。
6. 不得改变播放速度、镜像、补帧或叠加CSS骨骼动作。

## 重建

重建需要 Pillow、NumPy 与 OpenCV：

```bash
python -m pip install pillow numpy opencv-python-headless
python design/Baxian/build_articulated_48.py
```

脚本读取每个角色 `restrained-48-v3/source/keyposes.png`，输出48张PNG、WebP、GIF、spritesheet和动画元数据。
