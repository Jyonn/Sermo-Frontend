# 纵向绑定流程四方案

四版均沿用统一的渠道绑定语义，但取消横向进度条。

1. **连接清单**：完整说明后集中操作，最接近参考图。
2. **展开脊柱**：所有步骤纵向常驻，仅展开当前步骤；推荐用于统一落地。
3. **任务折页**：每一步是独立任务卡，更适合 Gotify、ntfy 等复杂配置。
4. **侧轨向导**：纵向轨道固定在左侧，右侧只呈现当前任务。

渠道栏支持电子邮箱、手机短信、QQ、Bark、ntfy、Gotify 和 PushDeer；切换后四版会同步更新字段、步骤、验证码目标和完成回执。顶部可以同步切换四版的“配置渠道 / 输入验证码 / 绑定完成”状态。验证码区域对应生产环境现有的 `VerificationCodeInput` 组件。

QQ 使用腾讯 QQ 官方应用图标，不使用 QQ 邮箱图标。
