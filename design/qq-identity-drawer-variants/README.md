# QQ号绑定 Drawer 设计方案

本地打开 `index.html`，顶部可统一切换“填写 QQ 号 / 输入验证码 / 已绑定”和深浅主题。

1. **邮箱直达**：单列直达，任务最清晰、迁移成本最低，推荐默认落地。
2. **双步凭证**：通过垂直步骤清楚解释永久绑定过程，适合降低用户顾虑。
3. **身份票据**：强化历史内容认领与归档语义，最有江中东西墙专属感。
4. **侧轨向导**：充分利用桌面 Drawer 宽度，步骤导航清晰，但移动端内容区更窄。

页面顶部同时展示调整后的“账号与安全”入口：独立 section、标题“QQ 号”、无 description，右侧仅显示“去绑定 / 已绑定”。
