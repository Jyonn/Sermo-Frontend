# 八仙聊天气泡设计研究

访问 `/design/baxian-bubble` 查看可交互设计稿。

## 方向

- 方案 01 · 内嵌题签：推荐。他方印章贴近气泡左内缘，己方贴近右内缘，并与最后一行文字对齐。
- 方案 04 · 暗纹水印：印章在相同方位成为低对比暗纹，同样跟随最后一行文字。

方案 02、03 已下架。保留方向均覆盖己方、他方、单行、多行、连续气泡和无气泡表情包；人物只在合并消息的第一条顶部登场，每个真实气泡独立展示印章，无气泡媒体不展示。

人物动画读取 `sermo-tools/baxian-frame-editor/exports` 的最新逐帧配置。每轮完整播放一次后停留在最后一帧 10 秒，再从第一帧重新播放。
