# 微信小程序 Header 系统提案

按照真实微信小程序的两层顶部结构设计：第一层为系统状态栏与灵动岛，第二层为产品导航栏与右上角原生胶囊。在这套共同安全区内提供四套可交互的统一 Header 方案：

1. 原生对衡
2. 下层命令轨
3. 信息标题舱
4. 上下文甲板

每套方案均支持切换聊天、广场、通讯、菜单四个一级 Tab；广场标题还可以继续切换投稿工作区，用于检查复杂状态下的空间占用。

四套方案共用同一动作规则：胶囊左侧仅保留一个淡绿色主动作；广场的消息通知、额度与搜索统一位于子 Tab 右侧。

本地打开 `index.html`，或在仓库根目录启动静态服务器后访问 `/design/miniprogram-header-systems/`。
