FRIENDEN · WECHAT HEADER STUDY

先尊重微信胶囊，
再建立产品自己的秩序。

右上角胶囊不是需要绕开的障碍，而是每个页面都必须共享的固定坐标。下面四套方案使用同一品牌语言、同一内容与真实安全区，只改变标题、上下文动作和二级导航的组织方式。

01 / Counterbalance

胶囊左侧对衡

高频动作压缩为胶囊左侧的单个方形按钮，二级导航与低频工具留在下一行。最接近当前结构，迁移成本最低。

适合直接落地优势是高度克制；代价是广场工具仍需要在窄轨道里精细分配。
02 / Command rail

双层动作轨

第一行只负责身份和标题，所有产品动作统一落到第二条命令轨。胶囊获得最彻底的独立空间。

信息最清楚四个 Tab 规则一致，广场扩展性最好；Header 会比方案一略高。
03 / Breathing room

标题整体下移

状态栏只留下 FRIENDEN 与微信胶囊，页面标题在下一行大幅展开。让系统控件和产品内容不再争抢同一水平线。

品牌感最强视觉呼吸最从容，双域标题也最清晰；纵向空间消耗最高。
04 / Context console

上下文控制台

当前 Tab 变成稳定的深色身份章，页面内状态与动作进入浅色控制条。导航感和工具感被明确拆开。

辨识度最高适合功能继续增长的阶段；相比前三套，视觉语言更强，需要四页一起更新。
