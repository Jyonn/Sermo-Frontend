# 投稿列表视觉提案

打开 `index.html` 可并排评审四种投稿列表设计。页面仅用于本地设计比较，不修改正式投稿 Tab。

- 01 静默收件箱：文字筛选与紧凑行布局，最大限度复用聊天列表。
- 02 流程侧标：头像连接成状态轨道，突出投稿推进过程。
- 03 双层稿签：轻量卡片将标题与最近消息分层，触控区域更明确。
- 04 审稿目录：自动区分进行中和已结束，适合投稿数量较多的用户。

预览宽度限制为 `400px`，并对齐正式前端的字号基准：投稿标题 `16px`、最近消息 `13px`、时间 `12px`、状态 `11px`、头像 `48px`。参与者与最近消息各占一行，不通过缩小文字伪造高密度。

顶部支持“我的 / 审批”和深色模式切换；每个方案内的状态筛选均可交互。“我的”列表展示审批人，并在多人投稿时标出共同投稿人数；“审批”列表展示投稿人，多人时使用叠放头像与“前两位姓名 +N”。完整成员名单仍放在投稿详情中，避免列表失去扫描效率。

建议优先评审 `01 静默收件箱`，再比较 `04 审稿目录` 是否更适合长期增长后的投稿量。
